# ADL-HAR Preprocessing Pipeline

A complete Google Colab pipeline for preprocessing the **Bruno et al. (2014) Public Accelerometer Dataset for Human Motion Primitives Detection**. The pipeline automatically converts raw accelerometer recordings into a machine learning-ready dataset using signal preprocessing, sliding-window segmentation, and handcrafted feature extraction.

## Key Features

- Automatic dataset folder detection
- Automatic reading of all activity recordings
- Noise reduction using median filtering
- 1-second sliding window segmentation
- Configurable overlap ratio
- Time-domain feature extraction
- Frequency-domain feature extraction
- Statistical feature extraction
- Automatic activity labeling
- CSV and Excel dataset generation
- Ready for clustering, classification, and deep learning

## Applications

- Human Activity Recognition (HAR)
- Activities of Daily Living (ADL)
- Machine Learning
- Deep Learning
- Clustering
- Healthcare Analytics
- Wearable Sensor Data Analysis
- Smart Home Systems
